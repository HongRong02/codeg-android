## 问题清单
### B16-1 从子页面返回后底栏不恢复
- 来源：P-005 真机复测（sit 合入 B10-misc 之后）
- 归属原任务：T58（上一轮修复：B10-1）
- 复现步骤：1. 打开"设置"标签 2. 列表往下滚动，底栏收起 3. 点"助手"进入子页面 4. 按返回键回到设置首页
- 预期结果：回到标签页时底栏显示
- 实际结果：底栏仍然收起；需要先往上滚动列表才会出现。（"滚回顶部""顶部下拉"两种情况上一轮已修好，复测通过）
- 定位：`A/feature/main/MainShell.kt` 的底栏可见状态。上一轮"按导航条目初始化可见状态"后，返回时恢复的是设置首页这个条目**之前保存的收起状态**。
- 预期修法：导航到任何非标签页的子页面、或从子页面返回标签页时，把底栏可见状态重置为显示（例如监听 `currentBackStackEntry` 的变化，目的地是底栏标签之一时设为可见）。保留滚动收起/恢复与上一轮的修复。
