# S2 显示真机测试

环境：vivo Android 11，服务器 `http://127.0.0.1:3082`（协调方配置 adb reverse），网页已登录。以下为待执行用例，本开发会话不操作手机。

| 编号 | 优先级 P0/P1 | 步骤 | 预期 |
|---|---|---|---|
| S2-01 | P0 | 系统关闭深色模式，强制停止后启动 App，进入已登录网页；再开启系统深色模式，强制停止后启动 | 浅色启动背景白色、深色接近 #0A0A0A，无反色闪屏；网页上下内容不被状态栏、导航栏遮挡 |
| S2-02 | P0 | 打开一个聊天，点击底部输入框，输入 `S2 keyboard`；反复收起/弹出键盘五次并切换多行输入 | 输入栏、发送按钮始终完整位于键盘上方；收起后恢复底部，无重复底部留白或持续跳动 |
| S2-03 | P0 | 网页主题选择跟随系统；进入聊天，输入未发送文字 `S2 retain` 并滚动到历史中部；下拉系统快捷设置切换深色/浅色，返回 App | 网页自动切换对应配色，未发送文字、当前聊天和滚动位置保留，无重新加载；系统栏背景和图标对比度同步 |
| S2-04 | P0 | 在网页设置中分别选择浅色、深色及其他可用配色，返回聊天；无需刷新页面 | 状态栏、导航栏区域与网页 theme-color 一致，浅底深图标、深底浅图标；其他网页配色不被算法二次变暗 |
| S2-05 | P0 | 分别启用系统三键导航和手势导航；打开聊天并弹出/收起键盘，横屏后重复 | 两种导航模式下输入栏和网页按钮可点，横屏刘海/系统栏不遮挡内容，键盘无双重 Insets |
| S2-06 | P1 | 系统字体设为最大，重启 App，比较同一网页聊天与默认字体设置 | 网页文字保持 100% 缩放，按钮和输入栏布局无因系统字体变大而错位 |
| S2-07 | P1 | 深浅色下分别打开原生服务器管理、错误页及更新提示（由对应功能可用时触发） | 使用中性背景、前景、边框及主色，文字可读，不出现默认紫色主色 |
| S2-08 | P1 | 保持网页显式浅色主题，切换系统深色，再切回网页跟随系统；在后台切换系统主题后恢复 App | 显式网页主题不被原生强制覆盖；恢复跟随系统后颜色正确，后台返回也同步 |
| S2-09 | P1 | 测试页同源主文档修改 html class/style、body 背景，以及新增/修改 theme-color（含 media）；删除 theme-color 后再改 body 为 rgb/oklch 色 | 无刷新同步系统栏；media 只取当前匹配项，无 meta 时使用实际 body 背景；透明背景有稳定底色 |
| S2-10 | P1 | 测试页嵌入异源 iframe，尝试调用 CodegShellDisplay.report；再导航到异源页面调用同名桥 | 非受信文档不能改变系统栏；返回所选服务器后主题同步正常 |

CI 检查：`verify.yml` 执行 `:app:check :app:assembleDebug :app:assembleRelease`。CI 不证明真机 IME 动画、WebView 版本兼容及视觉效果；上述项目由协调方执行。
