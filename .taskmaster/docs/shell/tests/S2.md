## V1 键盘焦点可见性回归

方案 1：保留 Compose `imePadding`，WebView 实际高度缩小时，等待最后一次布局变化后 120ms，再检查当前可编辑焦点；仅越界时执行 instant / nearest 滚动。高度增大取消待执行滚动，避免收键盘时拉动页面。监听文档 focusin，覆盖 SPA 内切换输入框；重复安装前清理监听和定时器。

只读检查网页源码：`src/app/layout.tsx` 的 viewport 未配置 `interactive-widget`；`src/app/workspace/layout.tsx` 的根节点使用 `fixed inset-0`，内部使用 `h-full min-h-0`，未发现工作区根节点强制 `100vh/100dvh` 的问题。因此先修复原生缩放后的焦点滚动，不覆盖网页 CSS，也不依赖网页新增键盘适配。
