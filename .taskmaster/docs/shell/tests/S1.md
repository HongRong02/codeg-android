# S1 导航真机测试

服务器 `http://127.0.0.1:3082`，网页已登录。链接样例可由协调方在测试服放置临时测试页；不修改正式网页代码。

| 编号 | 优先级 P0/P1 | 步骤 | 预期 |
| --- | --- | --- | --- |
| S1-01 | P0 | 打开左上角移动侧栏，按系统返回；再打开右侧面板并返回 | 每次只关闭抽屉，不离开当前页面 |
| S1-02 | P0 | 打开设置 Dialog；在其中打开下拉菜单，连续按两次返回 | 先关闭菜单，再关闭 Dialog；页面未后退 |
| S1-03 | P0 | 分别打开 Popover、Select、右键菜单、普通 Drawer 后按返回 | 关闭当前弹层；有拒绝关闭逻辑时不误退页面 |
| S1-04 | P0 | 从工作区进入另一路由，关闭全部弹层后按返回 | 返回上一网页路由 |
| S1-05 | P0 | 在没有历史的根页面按返回，2 秒内再按返回；重新进入 App | 首次显示“再按一次退出”，第二次退至后台，重新进入保留状态 |
| S1-06 | P0 | 根页面按返回，等待超过 2 秒再按返回 | 再次提示，不退出；快速连按不触发异步重复后退 |
| S1-07 | P0 | 点击同 origin 的 `/login` 链接；清除测试账号令牌后访问需登录页面 | 链接和服务端登录重定向均留在 WebView |
| S1-08 | P0 | 点击 `https://example.com`；再点击与测试服不同端口的 http 链接 | 系统浏览器打开；WebView 地址不变 |
| S1-09 | P0 | 测试页分别点击同源、外部的 `target=_blank` 链接及 `window.open(url)` | 同源在当前 WebView，外部在系统浏览器，无空白新窗口 |
| S1-10 | P0 | 点击 `mailto:test@example.com`、`tel:10086`、`market://details?id=app.codeg.android.mine` | 系统交给相应应用；未安装处理应用时 Toast 提示且不崩溃 |
| S1-11 | P0 | 点击未安装应用的 `intent://scan/#Intent;scheme=zxing;package=invalid.missing.app;S.browser_fallback_url=https%3A%2F%2Fexample.com;end` | 打开系统浏览器 fallback；无 fallback 时 Toast 提示 |
| S1-12 | P0 | 用测试页尝试导航到 `file:///sdcard/test.html`、`content://test/path`；新窗口尝试这些地址和 `javascript:` 地址 | 不加载文件、内容提供者或脚本地址，不崩溃（页面自身执行的脚本不属于导航拦截） |
| S1-13 | P1 | 同源地址测试主机大小写、显式默认端口；点击未知 scheme 及格式错误 intent | 默认端口等价仍在 WebView；未知或错误链接提示且不崩溃 |
| S1-14 | P1 | 连续打开、关闭多个新窗口；打开弹层后切换服务器再按返回 | 临时 WebView 及时释放；旧页面异步回调不影响新服务器 |
