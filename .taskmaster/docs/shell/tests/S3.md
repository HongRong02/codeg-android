# S3 真机测试用例

环境：vivo Android 11，adb reverse 已由协调方配置，服务器 `http://127.0.0.1:3082`，网页已登录。照片选择器在系统不支持时由 Activity Result 自动回退到系统文档选择器。

| 编号 | 优先级 | 步骤 | 预期 |
|---|---|---|---|
| S3-01 | P0 | 聊天页点附件上传；在系统文件界面选择一个 TXT/PDF 并发送 | 显示附件名称，发送后服务器可下载且内容一致 |
| S3-02 | P0 | 图片上传点相册，选一张图片；多选输入中选两张图片并发送 | 单选只返回一张，多选返回两张；预览和上传成功 |
| S3-03 | P0 | 图片上传点拍照，拍摄后确认并发送 | 返回图片预览，上传内容与照片一致，不请求 CAMERA 权限 |
| S3-04 | P0 | 分别在底部菜单、相册、文件界面、相机按返回取消；每次再点上传 | 取消不产生附件，再次上传可正常选择，页面不失去响应 |
| S3-05 | P0 | 打开图片底部菜单，向下滑动关闭或点击遮罩，再次上传 | 菜单关闭，再次上传正常 |
| S3-06 | P1 | 在文件输入分别设置 accept=.png、application/pdf、未知扩展名，打开选择器 | 分别过滤 PNG、PDF；未知扩展名允许所有文件 |
| S3-07 | P1 | 在测试页面用 accept=image/* capture 的输入打开相机；取消后再次确认拍摄 | 直接打开相机；取消可恢复，确认返回可读照片 |
| S3-08 | P1 | 在测试页用 accept=video/* 和 image/*,video/* 的单选及多选输入上传 | 可选对应视频或混合媒体，视频输入不显示拍照选项 |
| S3-09 | P1 | 选择器打开时旋转屏幕或由协调方触发 Activity 重建；返回后再次上传 | 无崩溃，旧请求取消，新页面能重新上传，不误收旧结果 |
| S3-10 | P1 | 禁用或移除相机处理应用后点拍照；或在系统选择器拒绝访问后重新上传 | 请求安全取消，无崩溃，下一次文件上传正常 |
| S3-11 | P1 | 文件多选输入选择多个不同文件；选择云盘文档后发送 | 返回所有所选文件，WebView 可读，服务端收到内容 |
