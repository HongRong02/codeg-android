# S6 真机测试用例

测试设备：vivo Android 11；正常服务器 `http://127.0.0.1:3082`（协调方配置 adb reverse，网页已登录）。以下为待执行用例，未声称已通过真机验证。

| 编号 | 优先级 P0/P1 | 步骤 | 预期 |
|---|---|---|---|
| S6-01 | P0 | 选择正常服务器后打开网页；观察状态栏下方；随后点击网页内部导航。必要时对主文档限速以观察进度。 | 主文档加载期间顶部显示 2dp 细进度条，完成淡出；SPA 路由切换不出现进度条。 |
| S6-02 | P0 | 添加并选择 `http://127.0.0.1:39999`（确保无服务监听）。 | 原生错误页覆盖浏览器错误内容，显示图标、标题、连接原因、当前服务器地址及重试和切换服务器按钮。 |
| S6-03 | P0 | 选择正常服务器，停止测试服务器后重新打开主页面；恢复服务器，点击“重试”。 | 错误期间遮罩保留，成功加载后消失，网页可操作。 |
| S6-04 | P0 | 错误页点击“切换服务器”，选择正常服务器。 | 打开服务器管理界面，选择后正常加载，旧错误和重试不残留。 |
| S6-05 | P0 | 将测试服主文档分别配置为 502、503、504，依次重新打开页面。 | 每次显示原生错误页和相应 HTTP 状态码；恢复主文档 200 后重试可恢复。 |
| S6-06 | P0 | 主文档正常返回，仅将一个图片请求及 `/api/` 请求配置为 503；重新打开页面并触发 API 请求。 | 不显示原生错误页，API 错误由网页处理。 |
| S6-07 | P0 | 服务器持续不可用，观察服务端访问日志至少 75 秒；之后点击“重试”。 | 约每 10 秒自动重试一次，总计最多 6 次；之后停止定时重试，手动按钮仍有效。失败不得重置次数。 |
| S6-08 | P0 | 用设备可访问的局域网测试服，断开 Wi-Fi 和移动数据后重新加载；错误页出现后恢复 Wi-Fi。 | 网络恢复自动重试一次；成功后遮罩消失。持续保持联网不会触发反复网络回调重试。 |
| S6-09 | P0 | 在错误页按 Home，再回到 App；在正常网页重复操作，并观察服务端主文档请求。 | 错误页回前台立即重试；正常页面回前台不 reload。 |
| S6-10 | P0 | 在错误页按系统返回键。 | S6 不消费返回事件，交由骨架默认返回行为处理。 |
| S6-11 | P1 | 输入 `http://s6-does-not-exist.invalid`；另将测试主文档延迟超过 WebView 超时。 | 分别显示可读 DNS、超时原因，按钮可用。 |
| S6-12 | P1 | 通过调试工具终止当前 WebView 的渲染进程（不要强停 App）。 | App 不崩溃，重建 WebView 并提示“页面已重新加载”。 |
| S6-13 | P1 | 错误页显示后切换系统中英文，并检查横屏、小屏及大字体。 | 文案对应语言，服务器地址可见，内容可滚动，按钮可点击。 |
| S6-14 | P1 | 在错误期间切换服务器、退出 App，再重新进入；观察网络回调与旧服务器访问日志。 | 旧错误计时和回调停止，新页面不被旧重试干扰。 |
| S6-15 | P1 | 测试 HTTPS 握手失败及无效证书。 | 握手失败若由 onReceivedError 上报则显示安全连接原因；无效证书路径需协调方补充 SSL 钩子后复验，不能忽略证书校验。 |

## 骨架限制

`ShellFeature` / `ShellClients` 未提供 `onReceivedSslError`，S6 无权修改协调方文件；因此无法可靠覆盖全部证书错误的原生遮罩。当前只映射 `ERROR_FAILED_SSL_HANDSHAKE`，不绕过 SSL 校验。
