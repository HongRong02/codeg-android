在 vivo Android 11 上执行；网页服务器填 `http://127.0.0.1:3082`，网页端已登录。更新源固定为 GitHub Release，与网页服务器无关。需协调方准备同签名的旧 release APK（例如 1.1.139）及更高 build-N Release；verify 产物采用提交计数版本号；本地默认 versionCode=2 的构建不能验证从 139 覆盖升级。

| 编号 | 优先级 P0/P1 | 步骤 | 预期 |
|---|---|---|---|
| S7-01 | P0 | 安装旧 release，启动并进入网页；GitHub 有更新时观察弹窗，滚动更新说明 | 显示新版版本号、纯文本说明、稍后和下载并安装；长说明可滚动 |
| S7-02 | P0 | 点稍后，退出重开，再切后台返回；24 小时内重复 | 同一版本不再提示；网页仍可使用 |

| S7-04 | P0 | 在未知应用设置开启允许，返回应用并确认系统安装；完成后打开应用 | 自动继续安装，覆盖成功且网页登录和服务器保留，版本升级 |
