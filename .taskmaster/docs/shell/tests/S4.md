## 网页源码只读盘点

`~/projects/codeg/src` 的 download/createObjectURL/toBlob 搜索：
- `lib/save-file.ts`：通用保存器，Blob + 脱离 DOM 的 a.download（配置/备份等导出调用方）。
- `lib/image-download.ts`：图片 fetch → Blob → a.download。
- `lib/mermaid-export.ts`：SVG Blob、PNG canvas 转换，经保存器下载。
- `components/ai-elements/message-thread.tsx`：Markdown Blob 导出。
- `components/settings/logs-settings.tsx`：日志 Blob 下载（最大 16 MiB，截断名称保留）。
- `components/canvas/canvas-view.tsx`：canvas data URL + a.download 导出 PNG。
- `lib/api.ts`：workspace/backup 的 HTTP 下载票据链接。
- 其他 createObjectURL/toBlob 命中（assistant-avatar、workspace-background、copy-image、browser/screenshot-markup、pet/sprite-url）属于预览/上传/剪贴板；最终走保存器或 a.download 时同样覆盖。
