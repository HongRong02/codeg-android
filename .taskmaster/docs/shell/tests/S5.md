# S5 服务器配置真机测试

环境：vivo Android 11；测试服 `http://127.0.0.1:3082`，由协调方配置 adb reverse。以下真机用例尚未执行。迁移用例先安装旧 1.1.x，保留数据覆盖安装新包；新安装用例使用独立干净数据环境。需准备第二个可区分的服务器和证书错误 HTTPS 测试地址。

| 编号 | 优先级 P0/P1 | 步骤 | 预期 |
|---|---|---|---|
| S5-01 | P0 | 干净安装启动；输入 `127.0.0.1:3082/path?q=1#x`，名称留空，点保存 | 探测成功后打开服务器网页；保存 origin 为 `http://127.0.0.1:3082`；登录由网页完成 |
| S5-02 | P0 | 输入 `ftp://example.com`、空地址、`http://user:pass@example.com` 分别保存 | 提示地址无效，不保存，不打开网页 |
| S5-03 | P0 | 输入 `http://127.0.0.1:1`，点保存；在失败对话框点取消；再次保存并点“仍然保存” | 明确提示无法连接；取消保留表单；仍然保存后选中该地址 |
| S5-04 | P1 | 输入受控丢包超时地址和无效证书 HTTPS 地址，分别保存 | 分别提示连接超时、证书验证失败；均可仍然保存；探测期间禁止重复保存 |
| S5-05 | P0 | 长按 debug 应用图标，点“切换服务器”；添加名称为“第二台”的另一服务器 | 打开原生管理页；显示两台服务器的名称、地址和当前选中标记；debug 快捷方式正常启动 |
| S5-06 | P0 | 管理页点第二台服务器条目；再切回第一台；关闭重启应用 | 每次点击关闭管理页并加载对应服务器；重启仍选中最后一台，不闪首次设置页 |
| S5-07 | P0 | 编辑当前服务器名称和带路径地址，保存；编辑非当前服务器 | 名称更新；地址仅存 origin；当前 origin 改变后加载新服务器；非当前编辑不切换 |
| S5-08 | P0 | 删除当前服务器先取消，再确认；随后删除最后一台，再添加测试服务器 | 取消不删除；确认后切到剩余服务器；最后一台删除后回首次设置页，再添加后直接打开网页 |
| S5-09 | P0 | 旧版添加两台服务器、各自登录并选中第二台；覆盖安装本版启动 | 保留原列表、名称和选中服务器；已有旧令牌时同源页面迁移后自动刷新一次，尽量免登录 |
| S5-10 | P0 | 迁移前让网页已有有效 codeg_token，打开对应服务器；迁移后在网页退出，再重新进入/重启 | 不覆盖网页已有令牌；网页退出后不再次注入旧令牌，不出现无限刷新 |
| S5-11 | P0 | 旧版存在令牌，服务器重定向至另一 origin；再返回原 origin | 外部 origin 的 localStorage 不收到旧令牌；仅原 origin 可以迁移；检查跳转中快速切换服务器也不串令牌 |
| S5-12 | P0 | 带旧令牌的服务器编辑成另一 origin，再打开该服务器 | 不将原服务器旧令牌注入新地址 |
| S5-13 | P1 | release 包长按图标切换服务器；系统中英文切换；小屏打开表单并弹出键盘 | release 快捷方式可用；中英文文案齐全；表单可滚动、保存按钮可达 |
| S5-14 | P1 | 管理页添加/编辑时取消，删除对话框点空白处；网络探测时旋转屏幕/离开页面 | 取消不改变存储；无崩溃；探测不阻塞主线程 |
